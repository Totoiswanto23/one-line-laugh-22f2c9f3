One original funny line of at most 200 characters: a bank's worry call turns a daily coffee into a cry for help — an entry for make.fun's [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) bounty ($2, 1st $1, 2nd $1). A judge model ranks the lines pairwise on how hard they land on a first read, surprise, economy, freshness and clean wording.

## The line

> My bank called to check if I was okay — apparently buying one coffee a day counts as a cry for help.

100 characters, one line. The turn is the bank treating an ordinary daily coffee as a cry for help, and the punch lands on the last words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt` by default), where the gate reads it. It refuses to write a line outside 1–200 characters or spanning more than one line.
